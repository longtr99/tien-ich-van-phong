# 🛠️ Tiện Ích Văn Phòng (macOS Version)

Bộ công cụ tự động hóa và hỗ trợ xử lý định dạng tệp văn bản Word, Excel, xoay trang, và làm sạch Macro tối ưu dành riêng cho hệ điều hành macOS.

## 🚀 Tính năng chính
- **Định dạng Font & Đoạn văn:** Chuẩn hóa nhanh kiểu chữ (Times New Roman, cỡ 14, giãn dòng).
- **Quản lý Hướng giấy & Xoay trang:** Chuyển đổi linh hoạt giữa trang đứng và trang ngang với Section Break.
- **Office Macro Cleaner:** Quét và loại bỏ an toàn các macro rác khỏi tệp `.docm` và `.xlsm`.
- **Giao diện AppleScript Native:** Thao tác trực quan bằng các hộp thoại chuẩn của macOS.
